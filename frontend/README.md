# Bowling Stats frontend

React + TypeScript (Vite). Start the backend first (`cd backend && .venv/bin/uvicorn app.main:app --reload`), then:

```
npm install
npm run dev      # http://127.0.0.1:5173, /api is proxied to the backend on :8000
npx tsc -b && npm run lint
```

See the root CLAUDE.md for the project rules.
